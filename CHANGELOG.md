# Changelog

## 0.1.0-rc1 — 2026-09-06

First engineering release candidate of ERPNext Vietnam.

- Universal Vietnam localization setup with versioned business profiles and auditable snapshots.
- TT99 statutory-account reference catalog and effective-dated COA semantic mapping.
- VAT classification, reporting taxonomy, reconciliation and evidence controls.
- PIT and social-insurance payroll compliance with immutable Salary Slip evidence/reconciliation.
- Canonical tax/BHXH declaration preparation and deterministic human-review exports.
- Provider-neutral e-invoice lifecycle, idempotent gateway, immutable acceptance archive and production-adapter certification gate.
- Read-only Health and Release Doctor diagnostics.
- Discoverable Vietnam Localization entry inside ERPNext Global Defaults.
- Vietnamese README with installation, operator workflow, module guidance, official legal-source links and release boundaries.
- MariaDB clean-install and migrate replay gate passed on Frappe 16.17.0 / ERPNext 16.16.0; HRMS 16.5.4 configured-site regression passed.

This RC does not certify legal/accounting acceptance and ships no real provider transport adapter without separately reviewed official technical contracts/schemas.
